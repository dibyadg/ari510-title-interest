# Data

The full dataset is available on Google Drive:

[Google Drive Link](https://drive.google.com/file/d/1HVghd9onHMDDt1a4nk5TVvfbpOO4RWs9/view?usp=drive_link)

## Files

| File | Description |
|------|-------------|
| `phase1_raw_titles.csv` | Full 638-title English dataset |
| `Annotator_1.csv` – `Annotator_5.csv` | Per-annotator assignments (50 titles each) |
| `annotation_master.csv` | 130 distinct titles used for annotation |

## Format

CSV with columns:

- `title_id` — unique identifier
- `title` — title text
- `domain` — YouTube, Reddit, Article, Podcast
- `source` — specific source
- `source_id` — original ID
- `url` — link to original content
